# Natural v1 · 岩屿自然写实材质

由 Codex 使用内置 imagegen 生成美术，Swift/AppKit 仅负责裁切、缩放和排列地形图集。现已通过 `natural-tools.js` 与 `game.js` 集成为完整内置材质包，保留原程序材质选项。

## 使用

推荐：暂停菜单 → 材质包 →「自然写实 · 地形与工具」。地形、工具、武器及快捷栏图标同步切换，正常游戏会保存选择。切换「标准」或「精细」即可恢复原材质。

也可单独导入地形 PNG：点击「导入 PNG」，选择 `stonisle-natural-128.png` 或 `stonisle-natural-256.png`。此入口只导入地形，不包含独立工具材质。

预览：打开 `/?preview=materials`，1–7 切换铁镐、铁剑、石镐、石斧、石铲、石剑、火把。此模式使用临时世界与背包，禁用存档和重置，不影响正常游戏进度。

工具表面：木柄、皮革握把、燧石、锻铁、黄铜、火把绑布。由 `tools-source.png` 的 3 × 2 图集提供，运行时每格缩为 256px，石质与金属使用不同光泽度。动物继续使用原材质。`manifest.json` 记录包的资产结构，尚未实现任意第三方 manifest 导入。

- 128 版：4096 × 128，32 格，约 744 KiB，适合默认使用。
- 256 版：8192 × 256，32 格，约 2.9 MiB。导入后会转成 data URL 占用浏览器存储，若提示空间不足请使用 128 版。
- 与当前 `Core.ATLAS_TILES = 32` 匹配；旧的 16 格版本不能直接使用。
- 导入尺寸提示已改为动态读取 `ATLAS_TILES`。

## 槽位（从零开始）

0 草顶、1 草侧、2 土、3 石、4 沙、5 水、6 树皮、7 年轮、8 树叶、9 木板、10 红砖、11 石砖、12 煤矿、13 铁矿、14 金矿、15 晶矿、16 雪。17–31 以岩石占位，未来新增方块应重新指定美术。

`materials-preview.png` 是 4 列 × 5 行美术预览，不能直接导入。正式图集的树叶槽位使用单独的 `leaves-source.png`，保留生成图片的透明通道；树叶整体偏浓密。

## 限制和后续

这是第一版 diffuse/albedo 颜色贴图，不包含法线或粗糙度贴图。已在游戏内检查地形、手持武器、工具与标准/自然材质切换，无控制台错误。生成提示要求可平铺，但沙地等大面积重复纹理仍可见，后续可进一步打磨。未改变世界光照、水面或动物模型。

验证：`node --check game.js`、`node --check natural-tools.js`、`node selftest.js` 均通过。实际预览截图见 `in-game-preview.jpg`。

## 重新打包

在项目根目录运行：`swift texture-packs/natural-v1/pack.swift`。

完整材质生成提示见 `prompt.txt`。树叶单独要求：写实小橡树叶、平视无透视、柔和均匀光照、克制自然绿色、细叶脉、覆盖约 85%、叶间透明孔隙、四边延伸可平铺、无文字边框。均使用内置 imagegen，未使用 API/CLI 生成。
